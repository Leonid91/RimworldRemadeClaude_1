# Rimworld Remade

Godot must be installed: download **Godot 4.7.2 – .NET** from the official website, [godotengine.org](https://godotengine.org/download/archive/4.7.2-stable/).
You also need the [.NET SDK 8 or newer](https://dotnet.microsoft.com/download).

## Windows

Unzip Godot into the game folder, then double-click `Play.bat`.

## macOS

Move `Godot_mono.app` to Applications, then in Terminal from the game folder run `./play.sh`.
