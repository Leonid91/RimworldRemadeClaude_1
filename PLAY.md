# How to play

1. Install the [.NET SDK 8 or newer](https://dotnet.microsoft.com/download).
2. Install Godot (required): download **Godot 4.7.2 – .NET** from the official website, [godotengine.org](https://godotengine.org/download/archive/4.7.2-stable/).
3. Download this repository (Code → Download ZIP) and unzip it.

**Windows:** unzip Godot into the game folder, then double-click `Play.bat`.

**macOS:** move `Godot_mono.app` to Applications, then in Terminal from the game folder run `./play.sh`.
